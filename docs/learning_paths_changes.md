# Learning path changes

`backend/data/learning_paths.json` was hand-authored with no sources. Any step that named a
specific company, app, institute, course, certificate, licence class, scheme or portal, or asked
for a government ID, was replaced with a generic step and a `_TODO`. No names or facts were
checked against a real source. `weeks` and `approx_cost_inr` are unchanged and remain unsourced
estimates; the app labels them as estimates.
